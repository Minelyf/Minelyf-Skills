# Canvas 动效短片（代码渲染视频）

模型不直接生成像素，而是**写一个渲染器**：画面是帧号的纯函数，浏览器逐帧取图，ffmpeg 编码。好处是文字、Logo、UI、图表永远清晰；改一句文案重渲即可；任意一帧都能单独、重复渲染出完全相同的结果。

不适合：写实人物、自然场景、实拍感镜头（这类需要视频生成模型补素材）。

## 一、技术约定（必须遵守）

- 单页 `index.html` + Canvas 2D，1920×1080，30fps。不用 DOM 动画、不用 CSS transition。
- `window.render(frame)`：只依赖帧号绘制整帧；**不读** `Date` / `performance` / `requestAnimationFrame`；随机数一律用带种子的伪随机（如 mulberry32），禁止 `Math.random`。
- `render` 返回本帧所有文字的包围盒数组 `[{s, x0, y0, x1, y1, g}]`，供 QA 自动检查越界和重叠（`g` 为分组名，同一行拆开的词用同一组，不算重叠）。
- 页面暴露 `window.FONT_SPECS`（如 `['700 88px "Noto Sans CJK SC"', '500 32px "JetBrains Mono"']`），截帧前逐个 `document.fonts.load`，再等 `document.fonts.ready`，避免中文回退成方块。
- 内部绘制函数不要和 `window.render` 重名（会无限递归），内部叫 `renderFrame`。
- 取帧用 `canvas.toDataURL` 导出，比元素截图快约 6 倍。
- 编码：`ffmpeg -framerate 30 -i frames/%04d.png -c:v libx264 -pix_fmt yuv420p -crf 18 out_silent.mp4`。
- 交付：`index.html`、`capture.js`、`qa.js`、`build.sh`、`audio/score.py`、`audio/master.py`、`out.mp4`。模板见 `scripts/` 与 `audio/`，完整示例见 `examples/botmux-feishu/index.html`。
- 脚本位置：把 `scripts/` 里的 `build.sh`、`capture.js`、`qa.js`、`package.json` 复制到 `index.html` 同目录，或整份放进其下的 `scripts/`。`audio/` 始终复制到 `index.html` 同级。脚本按自身位置找页面和配乐；`frames/`、`qa/`、`out.mp4` 写到 `index.html` 所在目录，不看当前工作目录。在任意目录执行 `bash build.sh`，或 `bash scripts/build.sh`。模板默认 1200 帧、混流 `-t 40`（40 秒示例）；片长不同时一起改 `capture.js`、`qa.js` 和 `build.sh`。

## 二、配色（亮色版，已被用户认可）

经验：深色底 + 电光蓝 + 荧光绿 被评价为“挫、廉价”；Apple 风近黑极简被评价为“还是挫、太素”。**亮色、多彩但克制**的版本通过。

| 角色 | 色值 | 用途 |
|---|---|---|
| 背景 | `#F7F8FC` | 浅灰白底，上叠 5 团缓慢漂移的柔和色块 + 极淡点阵 |
| 主文字 | `#1F2329` | 标题、正文 |
| 次级文字 | `#646A73` | 副标题、旁白式文案 |
| 弱化 | `#A2A8B3` | 占位、骨架 |
| 品牌蓝 | `#3370FF` | 主强调、聊天气泡（`#3370FF → #5E7BFF` 渐变） |
| 青 | `#00C2FF` | 辅助强调、连线光点 |
| 紫 | `#7B61FF` | 辅助强调 |
| 珊瑚粉 | `#FF6B9A` | 点缀 |
| 暖黄 | `#FFC53D` | 点缀、高光 |
| 卡片 | `#FFFFFF` | 白色玻璃卡，彩色柔和阴影 |
| 主角专属渐变 | 蓝 `#3370FF` → 紫 `#7B61FF` → 粉 `#FF6B9A` | 只给“主角”（如 BotMux 枢纽光球、关键词高亮） |

背景色块参数（中心、半径、透明度）参考：蓝 (260,180) r680 a0.22；青 (1680,200) r600 a0.20；紫 (1520,920) r680 a0.20；粉 (380,960) r600 a0.16；黄 (1000,520) r520 a0.12，各自以不同慢速正弦漂移。

配色比例：背景与白卡约占 75%，主文字深色约 10%，彩色强调合计不超过 15%；主角渐变只出现在一个主体上，避免满屏渐变。

## 三、字体与排版

- 中文：`PingFang SC` / `Noto Sans CJK SC`；代码：`JetBrains Mono` / `Menlo`。
- 主标题 72–96px 粗体，字距收紧约 2%；副标题 32–40px；注释 24px。
- 安全边距 110–120px，任何文字不出界、不重叠。
- 文案只用用户给定的句子，不擅自加宣传语或夸张说法（“彻底”“百分百”）。

## 四、动效（“灵动感”的来源）

用户反馈“太简单、没有动感、速度太快”之后，以下做法让片子通过：

1. **节奏放慢**：每句主标题完整可读停留 ≥ 1.5 秒（45 帧）；30 秒的分镜内容宁可拉到 40 秒。
2. **镜头一直在动**：整体缓慢推拉 / 平移，前后景视差（背景色块、点阵、主体移动速度不同）。
3. **元素始终“活着”**：主体轻微呼吸缩放、浮动，外圈渐变描边缓慢旋转，小卫星点绕行。
4. **弹簧缓动**：入场用确定性的阻尼弹簧（允许轻微回弹），同屏元素错开 4–6 帧依次入场；退场 8 帧淡出。
5. **形变转场代替硬切**：上一幕的某个形状直接变成下一幕的元素（如聊天气泡 → 整屏 → 缩成主角光球 → 收尾变成头像）。
6. **流动连线**：虚线 dash offset 随帧推进，上面跑光点，表达“数据在流动”。
7. **动态字**：主标题逐词弹起，关键词用主角渐变上色并扫过高光（高光只覆盖文字本身，不要扫到标点外）。
8. **一个主角**：宣传片要有一个贯穿全片的视觉主体（如产品枢纽光球），所有元素围绕它流入、流出、汇聚；给它最大的高光时刻（能力节点螺旋汇聚 → 膨胀 → 冲击波 → 弹出成果标签）。

禁止：粒子乱飞、无意义旋转、满屏渐变、炫技却看不清字。

## 五、配乐（代码原创，无版权风险）

- 只用 numpy 合成（无 scipy 时用 FFT 自实现滤波 / 混响）：失谐锯齿 pad（滤波逐渐打开 + 侧链式闪避）、乒乓延迟拨弦琶音、柔和 kick / clap / hat、圆润贝斯、钟琴小旋律。
- BPM 选能让一拍等于整数帧的值：30fps 下 **112.5 BPM = 16 帧/拍**，大转场落在小节线上。
- 从 `index.html` 读出场景帧号，做同步点：主角登场（低频轰鸣 + 闪光音 + 鼓组进入）、转场 whoosh、元素飞入 blip、卡片弹出 chime、高光时刻前 riser + 军鼓滚奏、冲击帧重低频 impact、结尾鼓组退出停在主和弦。
- 母带：`master.py` 用 ffmpeg loudnorm 到 **-14 LUFS**，真峰值 < **-1 dBTP**。
- 混流时视频流 `-c:v copy`，音频 AAC 192k 48kHz；保留 `out_silent.mp4`。

## 六、工作流

1. **拆分镜**：把用户描述拆成按帧号的分镜表（场景、时长、画面、屏幕文案、转场方式），文案只用给定文字。
2. **搭管线**：装 node、playwright + chromium、ffmpeg、`fonts-noto-cjk`、Python 3 与 numpy。按上面的「脚本位置」复制 `scripts/` 与 `audio/`，再执行 `bash build.sh`。
3. **写 index.html**：先定 `PAL` 调色板常量、缓动 / 弹簧 / 种子随机工具函数、文字绘制函数（记录包围盒），再按场景写 `scene1(ctx, f)…`，`renderFrame` 按帧号分派并处理交叉转场。
4. **快速迭代**：只渲染关键帧和转场中间帧（与 `index.html` 同目录时 `node capture.js --frames 30,90,…`；脚本在 `scripts/` 里时 `node scripts/capture.js --frames 30,90,…`），逐张看图、修问题，再全量渲染。
5. **QA（交付前必做）**：
   - `qa.js` 全片逐帧检查文字越界 / 重叠，问题帧数应为 0；
   - 同一帧在两个独立页面各渲染一次，MD5 一致、差异字节 0；
   - 抽 9 帧做 3×3 拼图 `qa/contact.png`，逐张肉眼看：越界、遮挡、截断、方块字、空镜；
   - `ffprobe` 确认时长、分辨率、帧率、帧数、音频流。
6. **配乐**：`python3 audio/score.py && python3 audio/master.py`，混流成 `out.mp4`；画波形 + 频谱图检查同步点。
7. **交付**：成片 + 拼图 + 精简 zip（只放源码、脚本、成片、拼图和报告，别把几百张帧图打进去，聊天附件上限 25MB）。附上验收结果、修过的问题、偏离分镜的地方。

## 七、常见坑

- 分镜里“每 2 帧一个字符”的打字效果可能放不下时间窗：保留速度并说明偏移，或问用户是否压缩。
- 镜头推进时容器里的小字会冲出安全区：推进中段隐藏小字，用整屏大字承接。
- 汇聚 / 飞行的碎字互相碰撞：提前淡出、拉开落点，或让数字跟随柱顶一起升起。
- 设备汇聚时文字叠在一起：加快淡出，收尾窗口提前进场避免空镜。
- 圆角函数要同时支持数字和数组半径，否则柱子和顶栏会整块消失。
- 不要用真实商标素材：品牌用自绘圆角标 + 文字。
