# 风格：结论先行的信息图

浅灰底，最多三种颜色各管一块，白卡片装内容，黄色只留给"要点"和需要提醒的数字。适合数据汇报、现状一图、规划、闭环流程。

## 颜色

| 用途 | 主色（边框、标签、柱） | 文字色 | 浅底色（面板填充） |
|---|---|---|---|
| 红 | `#fe2c55` | `#e0244b` | `#ffedf1` |
| 青 | `#00a8a3` | `#008c88` | `#e4fbfa` |
| 墨 | `#161823` | `#161823` | `#f1f1f3` |
| 黄（只做强调） | `#d9941e` | `#b5770f` | `#fff8e6` |

- 画布底色 `#f7f8fa`，正文 `#1f2329`，次要文字 `#6b6e76`，连线 `#9a9ca3`，条形图轨道 `#eceef1`。
- 一张图里按"类别"分色：两类用红 + 青，三类加墨。同一份文档里几张图的配色对应关系保持一致（比如“阶段一”一直是红）。
- 黄色不当类别用：只给最后的要点条、风险/代价标签、需要大家注意的数字（如误召、限流）。

## 版面

- 画布宽 1000，四周留 40，内容区 40～960。高度随内容。
- 从上到下：**标题**（26 粗，完整结论）→ **副标题**（16 灰，范围和来源，用 ` · ` 隔开）→ **2～4 个面板** → **要点条**（黄底黄框，第一行粗体"一句话：……"）。
- 两层就够：面板（浅底色 + 2px 同色框，圆角 8）里放白卡片（1.5px 同色框，圆角 6）。卡片里一个粗体小标题 + 最多三行正文。
- 间距按 8 的倍数：卡片之间 16，面板之间 24。

## 常用版式

| 要讲的东西 | 版式 |
|---|---|
| 一组关键数字 | 一排数字卡（大数字 + 粗体说明 + 一行灰字），下面接柱状图或比例条 |
| 结果分布、各类占比 | 横向比例条：标签 + 灰轨道 + 彩色填充 + 右侧百分比，重点那条换黄色 |
| 现状 / 我们在哪 / 接下来 | 表格式：左侧一列彩色标签卡，右边三列白卡，一行一个业务 |
| 流程、闭环 | 一排编号卡片 + 实心箭头连线，回流用虚线 |
| 二选一的决策 | 上面一个问题药丸，左右两个分支面板，下面一个"两边都要"的底座 |

## 部件

都在 `scripts/board.py` 里：`title`、`panel`（带编号圆点的分区）、`card`、`kpi`（数字卡）、`bars`（横向比例条）、`columns`（柱状图）、`pill`（药丸标签）、`takeaway`（要点条）、`est`（估算文字宽度）。
