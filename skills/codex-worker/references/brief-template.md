# Brief 与返工模板

复制所需模板，用可观察的要求替换尖括号中的占位内容。涉及界面时给出参考、关键状态和需要检查的视口。

## 首次派单 Brief

```markdown
## 目标与交付物
- <用户要解决的问题、预期结果和具体交付物>

## 高层设计
- <选定的方案、模块边界、入口与数据流>
- <需要遵循的现有实现、设计参考和关键取舍>

## 关键细节约束
- <可修改的文件或模块、接口契约、兼容要求>
- <典型输入、边界情况、错误处理与回退行为>
- <适用时给出布局、交互、文案和关键界面状态>

## 红线
- <禁止改动的区域、禁止执行的操作、禁止写入的敏感信息>

## 验收标准
- <在什么条件下执行什么操作，观察到什么结果即通过>
- <构建和测试命令、预期结果，以及适用时需提供的截图>
- <回报变更文件、实际验证结果和仍待确认的问题>
```

## 返工与迭代 Resume

```markdown
## 本轮目标
- <同一任务的新增要求或待修问题>

## 未通过点与复现依据
- <验收项、复现步骤或命令、实际结果、相关文件或截图>

## 期望行为与改动范围
- <期望结果、需要修改的位置和新增约束>

## 需要保留的既有成果
- <已通过的行为、接口、视觉状态和用户已有改动>

## 复验与回报
- <重跑本轮相关检查和受影响的既有检查，说明实际结果>
```
