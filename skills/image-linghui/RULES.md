# 本地图片绘制规则

## 画布与可读性

- 用户指定尺寸优先；否则宽约 1600–1700 逻辑像素，高度随内容。Insight Brief 用 1000 宽，外边距 40。SVG 明确设置 width、height 和 viewBox。
- 文字保留为 text/tspan，显式指定本机可用的中文字体及后备字体。CJK 字宽约 1em，拉丁字约 0.6em；按实际渲染调整，长文本主动换行，避免缩小到不可读。
- 一般正文至少 16px；1000 宽画布可用 14px 标签。配色、对比和视觉层级服从可读性。
- 优先矩形、圆形和简洁连接线。箭头可用标准 SVG marker；确保箭头方向及终点正确。
- 本地渲染可使用曲线、透明度、渐变、阴影和裁切，按风格需要使用并验证效果。不存在画板的字体、颜色导出或描边档位限制。
- 模板里的几何造型和纯色要求仍可作为风格选择；不把特定平台限制当成本地渲染器能力限制。

## 内容

- 画面呈现用户要表达的内容，不默认印上提示词、制作过程、工具名或模板名。用户明确要求显示时遵从。
- 数据、引语保持准确；示意位置和比例不能伪装为真实统计。必要的来源、图例及导航锚点可以保留。
- 信息过密时拆成多张图，每张围绕一个问题。

## 渲染与验收

使用环境现有的渲染工具。例如已安装 CairoSVG 时：

```bash
python -m cairosvg diagram.svg -o diagram.png -s 2
```

倍数根据目标尺寸调整；需要透明背景时不添加背景矩形。不能把 SVG 改后缀冒充 PNG。
实际打开最终 PNG 检查：中文缺字、溢出、重叠、裁切、对齐、留白、对比、箭头方向及分辨率。修复后重渲染并复查。交付真实可打开的 PNG，附 SVG 源文件。
